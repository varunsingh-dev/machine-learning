# 🌳 Decision Tree

## 📖 Overview

Decision Tree is a Supervised Machine Learning algorithm used for both Classification and Regression tasks. It makes decisions by splitting data into branches based on feature values until it reaches a final prediction.

---

## 🎯 Objective

The objective of Decision Tree is to create a tree-like model that predicts the target variable by learning simple decision rules from data.

---

## 🧠 Types of Decision Trees

### 1. Decision Tree Classifier
Used for classification problems.

Examples:
- Heart Disease Prediction
- Spam Detection
- Loan Approval

### 2. Decision Tree Regressor
Used for regression problems.

Examples:
- House Price Prediction
- Sales Forecasting

---

## ⚙️ Working of Decision Tree

1. Select the best feature.
2. Split the dataset.
3. Create decision nodes.
4. Continue splitting recursively.
5. Stop when a leaf node is reached.

---

## 📊 Important Concepts

- Root Node
- Decision Node
- Leaf Node
- Information Gain

- Entropy

## ✅ Advantages

- Easy to understand
- No feature scaling required
- Handles numerical and categorical data
- Easy to visualize

---

## ❌ Disadvantages

- Can overfit
- Sensitive to noisy data
- Large trees become complex

## 💼 Interview Questions

### What is a Decision Tree?

A tree-based supervised learning algorithm used for classification and regression.

### What is Entropy?

Entropy measures the impurity or randomness in the dataset.

### What is Gini Index?

Gini Index measures the probability of incorrect classification.

### Difference between Entropy and Gini?

Both are impurity measures used to decide the best split in a Decision Tree.
