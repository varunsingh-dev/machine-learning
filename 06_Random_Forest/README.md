# 🌲 Random Forest

## 📖 Overview

Random Forest is an Ensemble Machine Learning algorithm that combines multiple Decision Trees to make more accurate and robust predictions. It is used for both Classification and Regression problems.

---

## 🎯 Objective

The objective of Random Forest is to improve prediction accuracy and reduce overfitting by combining the results of many Decision Trees.

---

## 🧠 Types of Random Forest

### 1. Random Forest Classifier
Used for classification tasks.

Examples:
- Heart Disease Prediction
- Spam Detection
- Loan Approval
- Customer Churn Prediction

### 2. Random Forest Regressor
Used for regression tasks.

Examples:
- House Price Prediction
- Sales Prediction
- Stock Price Forecasting

---

## ⚙️ How Random Forest Works

1. Create multiple random samples from the dataset.
2. Build a Decision Tree for each sample.
3. Each tree makes its own prediction.
4. Final prediction is based on majority voting (classification) or average prediction (regression).

## 💼 Interview Questions

### What is Random Forest?

Random Forest is an ensemble algorithm that combines multiple Decision Trees to improve prediction accuracy.

### Why is Random Forest better than Decision Tree?

Because it reduces overfitting and provides more stable predictions.

### What is Bagging?

Bagging (Bootstrap Aggregating) creates multiple datasets using random sampling and trains separate models on each.

### What is Ensemble Learning?

Ensemble Learning combines multiple models to produce a better final prediction.

---

## 📝 Summary

Random Forest is one of the most powerful supervised learning algorithms. It achieves better accuracy than a single Decision Tree by combining predictions from many trees.
